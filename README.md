# Meow Racing

Meow Racing is a 3D browser racing game (Three.js + cannon-es + anime.js) served by an Express Web Service. Race across multi-lane highways, weave through AI traffic, grab boost pickups, collect coins and crowns, unlock car skins in the shop, and track your progress across 10 levels. All game code was generated by an AI assistant.

## Tech Stack

| Component / Library | Version | Delivery / Usage |
| :--- | :--- | :--- |
| Three.js | 0.160.0 | CDN importmap (3D scene, meshes, lighting, camera) |
| cannon-es | 0.20.0 | CDN importmap (3D rigid-body physics and collision detection) |
| anime.js | 3.2.2 | CDN importmap (UI and HUD animations) |
| Express | 4.x | npm dependency (Node.js Express static file server) |

## Run Locally

Install dependencies and start the server:

    npm install
    npm start

Then open `http://localhost:3000` in your browser.

## Controls

| Input | Action |
| :--- | :--- |
| Arrow Keys or WASD | Steer left/right and accelerate/brake |
| Space | Activate boost |
| Enter | Start race |
| R | Restart current run or level |
| C | Change car color |
| M | Toggle mute |
| Touch Buttons | On-screen steering, acceleration, braking, and boost on mobile devices |

## Features

* **10 Levels:** Play through 10 levels featuring distinct visual themes and rising difficulty.
* **5-Lane Traffic:** Navigate 5 lanes populated with sedan, sports, van, and truck AI vehicles that perform lane changes.
* **Boost System:** Collect boost pickups to charge the boost meter, complete with exhaust flames and speed lines.
* **Prize Screen:** Receive end-of-run rewards including coins, crowns, distance bonus, and time bonus.
* **Shop:** Spend earned coins in the shop to unlock new car skins.
* **Wallet & Progress:** Persist wallet coins, unlocked skins, settings, and level progress in `localStorage`.
* **Mobile & Performance:** Includes mobile touch controls and performance settings for smoother play.

## Deploy to Render

Deploy using the included `render.yaml` Blueprint as a free Render Web Service (`plan: free`, `env: node`). Render runs `npm install` as the build command and `node server.js` as the start command. The Express server binds to `process.env.PORT` or falls back to port `3000`.

## Notes

* Requires a modern browser with WebGL and JavaScript `importmap` support.
* Frontend libraries (Three.js, cannon-es, and anime.js) are loaded from CDN on first load.
* Uses no external 3D model files; 3D geometry is generated in code.
* Meow Racing is a fan-made educational clone with an original name and game concept.
