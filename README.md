# Meow Racing

A browser-playable 3D racing game inspired by the GameSnacks title *FullSpeed Racing*. Drive a low-poly sports car down a 5-lane tropical highway, dodge traffic, collect coins and crowns, hit checkpoints to extend the timer, and use turbo to go faster.

All game code was generated by DeepSeek. No external 3D model files — every mesh (car, road, palm trees, buildings, ocean, sky) is built procedurally with Three.js, with textures drawn on canvas at runtime.

## Tech stack

## Architecture

- `js/config.js` — all tuning constants (speed 62.5, gravity 9.8, 5 lanes, traffic, scoring, timings, palettes) and helpers.
- `js/car.js` — procedural low-poly car builder + `Car` controller (steering, wheel spin, drift, turbo).
- `js/world.js` — `World` class: road, lanes, guardrails, traffic pool, checkpoints, pickups, ocean, beach, palms, buildings, sky, lighting.
- `js/effects.js` — `Effects` class: anime.js-driven speed ribbons, turbo glow, collision bursts, score popups, HUD tweens, checkpoint pulse, overlays.
- `js/game.js` — main loop, cannon-es physics, state machine (MENU → PLAY → GAME_OVER → WIN), input, chase camera, scoring.

World recycling keeps the player near the origin while road segments, traffic and scenery flow past, giving an endless highway.

## Deploy to Render (free Web Service)

`render.yaml` is a Blueprint for a free Node web service:

- **Type:** Web Service
- **Environment:** Node
- **Plan:** Free
- **Build command:** `npm install`
- **Start command:** `node server.js`

Options:
1. In the Render dashboard, create a new **Web Service** from your GitHub repo; Render detects `render.yaml` automatically.
2. Or use the Blueprint flow: *New → Blueprint* and point at this repository.

The server binds to `process.env.PORT || 3000`, as required by Render.

## Notes

- Requires a browser with WebGL + ES module importmap support (Chrome, Edge, Firefox, Safari 16.4+).
- Libraries are fetched from CDNs on first load; the browser caches them afterwards.
- No analytics, cookies, or server-side game logic.
- Fan-made educational clone. Three.js, cannon-es and anime.js retain their licenses. "Meow Racing" is an original name; the original *FullSpeed Racing* concept belongs to GameSnacks / Google.
